# Dashboard / Observability Layer

**Current release: v3.5** (2026-08-02) · [Source](https://github.com/Rozzzsie/Rozzzsie/tree/main/dashboard)

**Live: [rozzzsie.github.io/Rozzzsie/dashboard/](https://rozzzsie.github.io/Rozzzsie/dashboard/)** — GitHub Pages serves the rendered `index.html` on every push to `main`. HTTPS enforced. Open `dashboard/index.html` directly in a browser to read locally — the render is fully self-contained (CSS in `assets/`, no JS).

## What this is

The dashboard is the OS observability surface — a render of the governance state into a shape leadership and external readers can browse without diving into the protocol doc, the retro narratives, or the proposals file.

Industry harness dashboards (LangSmith, Langfuse, DashChat) surface telemetry — tokens, latency, error rates, eval scores. Same *shape* (quantitative metrics on a temporal axis), different *semantics*. Rozzzsie's dashboard surfaces **governance evolution**: a governance health score over the integrity of the loop that catches failure, proposal authoring per cycle, an unscored defect inventory, learning-layer invocation trend, dispatch distribution by role, and per-finding decision velocity. The arxiv anchor is *evaluation as continuous governing function, not terminal checkpoint* ([EDD 2024](https://arxiv.org/abs/2411.13768)) — that principle is what distinguishes this layer from a Langfuse/LangSmith clone.

**Why scope-honest matters.** A polished-looking dashboard with one data point is the kind of thing a sharp reviewer (CTO, interviewer, peer architect) catches and discounts. Sprint-1 is honest: this is what one retro looks like, here's the rendering contract, the next retro's sidecar will auto-render here when it lands. That's the L5-evidence move — *the OS observes itself* — without faking trends from n=1. Sprint-2 unlocks multi-retro trend rendering once 3+ sidecars accumulate (gated on schema v1.0 stability review at 2026-05-15).

## Release notes

### v3.5 — 2026-08-02 (two operator decisions resolved, both by deleting something)

- **Rail names are public vocabulary, so the mapping that hid them is gone.** The renderer had been translating internal rail names into generic role phrases before printing them. The 15 retro sidecars published *in this same repo* carry those names 298 times in plaintext — so the mapping was concealing on one surface what the data beside it had always published, which reads as confidentiality coverage while providing none. Names now print directly, and the regression test that banned them is deleted rather than narrowed. **Its assertions did not change; only their status inverted** — the same list of names that used to prove a leak now proves correct output, which is the sharpest available reminder that a green test means the code and the test agree, never that either agrees with policy. Protocol identifiers remain banned and are a separate question.
- **`discipline_metrics` may be redacted to null, so it is no longer a required block.** The two contracts were in real conflict: a required-field list says *absent means drift*, the redaction rule says *absent is a legitimate state when the counts are traceable to a person*. Requiring the sub-keys would fail the render on a correctly-redacted sidecar, and put the author under pressure to invent numbers to get a page. Redaction wins. **The cost is stated rather than absorbed:** drift in those four keys is now invisible to the schema, and the two dials fed by them render as unknown — never as zero.
- **The four discipline rows are removed from the page** at the operator's request; the figures were not decision-relevant to an external reader. The dials they feed are unaffected.

## Architecture (sprint-1)

- **Source data**: each P10 retro emits a YAML sidecar parallel to the narrative `.md` (P10 was P8 in v3.5.x; the v3.9.3 cascade renumbered the weekly retro slot). Filename pattern: `_retro/YYYY-MM-DD-pN.yaml` (private; sanitized excerpts surface here for the public render).
- **Schema**: `render.py` § `SIDECAR_SCHEMA` — one surface, and it is the enforced one. A missing required field fails the render with `rc=3`; an undeclared field or block warns. It carries the field-intent documentation too, so there is nothing to keep in sync. Until 2026-08-02 the schema lived in a second, private, unparsed file that this line used to point at — a path no reader of this repo could ever resolve.
- **Render**: HTML single-page rendered from the sidecar(s) and dropped into this `dashboard/` subtree on push. GitHub Pages serves the same subtree at `rozzzsie.github.io/Rozzzsie/dashboard/`.
- **Update cadence**: sprint-1 ships static-rendered v1.x from a single retro. Sprint-2 unlocks multi-retro aggregation once 3+ retros' sidecars exist.
