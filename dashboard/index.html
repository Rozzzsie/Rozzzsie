Meta-finding
Two metrics in this dashboard were found to be counting a MECHANISM rather than an EFFECT, one cycle after the prior retro named that exact class in its own provenance block. The sharper of the two is the external-validator count: it can only ever read zero, because the two dispatch paths it recognises are both disabled for the agent by configuration, while the sanctioned path — a shell call to the review companion — is counted by neither. The session log records five real invocations of that companion inside this window, every one of them returning an account-level quota wall. A published zero that is structurally incapable of being non-zero is not a measurement of disuse. Neither instance was caught by an instrument; both were caught by holding two facts together.
