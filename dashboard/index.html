A MATCHER IS A HYPOTHESIS ABOUT A FORMAT YOU DID NOT AUTHOR, AND HALF ITS FAILURES RETURN A PLAUSIBLE NON-ZERO. Six instances in a single ritual, each producing a confident finding-shaped wrong answer: a date pattern demanding a delimiter the entries do not carry reported ZERO changelog entries for the week on a file modified that same hour (true figure 96, corpus 70 → 332); a structural-field query keyed on the wrong envelope shape returned 307 unclassified records and an all-zero health table; a card-delimiter guess returned 4 cards against 1,439; a verdict pattern returned zero verdicts on a trace that had passed its own blocking gate, briefly resembling a hole in a Tier-1 gate; a status matcher counted every status value rather than the one asked for, reporting 62 open proposals against 13; and a heading pattern found zero version banners in a file full of them. THE GOVERNING RULE HAD BEEN PROMOTED FORTY MINUTES BEFORE THE FIRST INSTANCE, BY THE SAME AUTHOR, WHO HAD READ IT AT SESSION START — and it did not fire once. The reason is structural rather than attentional: the two guards covering this family trigger on a grep's SILENCE and on a ZERO-MATCH sweep respectively, and three of the six returned non-zero values. A non-zero result is its own positive control and passes affirmatively. Aggravator: the pinned always-on tripwire described the rule as bounding what the instrument can REACH; every object here was fully reachable, so an author who checks the tripwire, confirms reachability and proceeds has used it CORRECTLY and still ships the wrong number. What worked six times out of six was a contradiction between the result and one independently-known fact about the same object — file-modified-today versus zero entries, a live error rate versus columns summing to zero, ten thousand lines versus four cards. Fix is ORDER, not vigilance: derive the format from the artifact before writing the pattern.

THE PUBLIC DASHBOARD HAS BEEN PUBLISHING A DISCIPLINE RATE DERIVED FROM FIRE COUNTS AND LABELLED AS TURNS — DENOMINATOR INFLATED 13.5x. The metrics tally that feeds this very file increments its counter once per firelog RECORD and emits the ratio with the literal comment 'substantive turns'. In a long agentic turn the post-tool hook re-grades the SAME last-completed turn once per tool call, so the raw figures for this window were 2500 of 6922 — a rate of 36% and a denominator implying roughly 182 substantive turns per session across 38 sessions. Deduplicated on the per-turn signature the hook already writes into every record, the true figures are 97 missed of 511 graded turns, a rate of 19.0%. Both numerator and denominator are inflated and the numerator inflates MORE, so the published rate is nearly double the real one. This is the same fire-versus-turn confusion the private doctrine has recorded against a triage counter for weeks; what is new is finding it in a PUBLISHED metric, where the reader has no access to the underlying log and no way to sanity-check the denominator. Caught by contradiction: the 36% figure disagreed with this same cycle's response-discipline audit, which found the marker largely healthy. The corrected figure is published below; the tally itself is a code change and is filed rather than patched inside a retro.

Meta-finding
A matcher is a hypothesis about a format you did not author, and the guards written for this class all key on a ZERO. Six times in one ritual a pattern was written from expectation rather than derived from the artifact; three of the six returned a plausible NON-ZERO — 307, 4, and 62 — which no existing trigger can fire on, because a non-zero result IS its own positive control: it proves the object was reached, the tool ran, and the pattern compiled. It passes affirmatively, so nothing invites a re-check. The pinned tripwire made this worse rather than better: it summarized the governing rule as bounding what an instrument can REACH, and every one of these objects was fully reachable, so consulting the tripwire correctly routed the author away from the arm that was failing. What actually worked, six times out of six, is not a rule and is not mechanisable — a contradiction between the result and one fact known about the object WITHOUT the matcher. A seventh instance fired while WRITING rather than reading: a capture file was labelled as a verbatim agent return without being opened, when it in fact held the full transcript, a superset. The false label was the flattering one.
