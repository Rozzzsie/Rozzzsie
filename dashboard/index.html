Meta-finding
THE RECORD EXISTS; THE CONSUMER DOES NOT. Four independent findings this cycle reduce to one shape. A status token is written correctly and nothing reads it on a schedule. A watch condition banks a numeric trigger with no reader. A proposal queue accretes to eleven items, oldest ninety-eight days, because nothing consumes "pending". And a health audit is cited twice in the live index as "(existing)" while the protocol that would run it contains no such step — it was specified against the retrospective's PREVIOUS protocol number, and at the renumber someone updated the citation and never carried the audit across. The generalisation is that a maintained pointer is not evidence of a live referent, and a parenthetical that vouches for its own target inverts the reader's burden: a bare citation invites "is there one?", while "(existing)" answers the question before it is asked.
