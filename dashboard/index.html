Meta-finding
This cycle's sharpest findings were numbers and pointers that were faithful to their input and wrong about what the input was. The metrics tally counted 132 external-validator launches, and every one was the always-loaded rules file quoting the command it says cannot be launched. A lesson deferred five weeks ago said it was filed on a backlog row, and that row had closed without it, so it sat on no ledger. Four quality traces counted hook fires or responses as turns. A guard on sub-agent returns logged thousands of agents that left no transcript, and what spawns them is still unattributed. In each case the count or pointer resolved and its arithmetic was right; it had been keyed on a string, an id or a record kind rather than on the thing it was meant to stand for. The corrected figure is published here, and each fix is on a ledger.
