About this dashboard (sprint-1 v1.1)

This is a single-retro snapshot rendered from retros/2026-04-24-p3.yaml — the most recent P8 weekly retrospective in the Rozzzsie governance OS. The render is mechanical (hook-side / build-side); judgment slots and multi-retro trend graphs are sprint-2 surface, gated on the schema surviving 3+ retro cycles.

Industry harness dashboards (LangSmith, Langfuse, DashChat) surface telemetry — tokens, latency, error rates, eval scores. This dashboard surfaces governance evolution: proposal lifecycle from authoring to executed, hook fire-rate health, checkpoint-bar discipline trends, Luma tally by category, decision velocity per retro, family-pattern detection across weeks. Same shape (quantitative metrics on a temporal axis), different semantics (governance health, not service health). The arxiv anchor is EDD 2024 — "evaluation as continuous governing function, not terminal checkpoint."

The narrative .md retro is private; this .yaml sidecar is the public-grain summary, sanitized for stakeholder names and specific workspace paths. Render provenance: dashboard/render.py reads the sidecar and emits this index.html on push. Sprint-2 unlocks multi-retro trend rendering once 3+ sidecars accumulate.
