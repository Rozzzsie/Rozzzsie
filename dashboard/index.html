Meta-finding
Most of this week's failures were recurrences. Of the five gap classes found, four already had a written rule that held on paper and failed in practice. The one genuinely new failure was worse: an instrument deleted the evidence of the thing it measured. A leak canary built to find test records in the production log also classed a live governance gate's records as test records, and a purge built on the same predicate removed them. The hook audit then reported the gate as absent. The cycle responded with mechanisms, not more wording: a setting that removes the capability behind the most frequent recurrence, and a review question that asks where each check gets its expected answer. The window was six days, because the retro was pulled a day early.
