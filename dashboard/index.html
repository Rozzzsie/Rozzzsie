Meta-finding
Two of this cycle's sharpest findings were about records that never existed, and nothing reports a record that was never written. The public dashboard's learning-agent count placed each run by the date its transcript file was last written, in UTC, so every retro's own run was counted a week late, and last cycle published zero for a week in which it had run. The operator caught that by knowing the run had happened. Separately, four hooks call a logging function that was never defined, and an error suppression on the call hid it, so three of them have never appeared in the hook audit at all. The audit lists hooks by the records it finds, so their absence read as nothing to report. The recurring gap classes from last cycle grew, except one: the habit whose capability was removed by a setting fell from eleven instances to five, and the one attempt after the guard went live was blocked. Removing a capability worked where adding wording had not.
