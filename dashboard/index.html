Meta-finding
The sharpest instrument failure this cycle was the retrospective's own bookkeeping, and it failed three times in one direction. A housecleaning pass reported the size of its edit set as the size of the stale set. An approved build recorded as "filed" sat on no ledger for a week. Four findings the prior cycle carried forward were on no work list at all. Each record was accurate about what had been done and silent about what had not, so every re-read confirmed it. None was caught by an instrument aimed at it; all three surfaced from a full census run for a different reason.
